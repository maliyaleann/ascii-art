# ASCII Studio

A C++ multimedia project exploring image processing and ASCII art generation.

The goal is to build an interactive application that converts images, prerecorded videos, and live webcam input into ASCII art.

## Features

### Currently implemented
- Image-to-ASCII conversion using `stb_image.h`
- Dynamic output resizing
- Grayscale brightness calculations
- Region-based pixel averaging
- Video loading and playback using OpenCV
- Grayscale video processing

### Planned features
- Real-time ASCII video playback
- Live webcam-to-ASCII conversion
- Colored ASCII rendering
- Adjustable character density and contrast
- Graphical interface and rendering controls

## Technologies

- **Language:** C++
- **Libraries:** stb_image.h, OpenCV
- **Development environment:** VS Code, MSYS2 UCRT64

## Project Status

🚧 Work in progress — currently developing video-to-ASCII conversion.
